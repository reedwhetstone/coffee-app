# Purveyors Brand 2.0 Image-generation Record

## Method

All five concept assets were generated with the built-in `image_gen` tool using the `imagegen` skill workflow. No CLI/API fallback was used. Final outputs were copied into `assets/concepts/`.

The generated screens are directional. They are not evidence that the depicted copy, metrics, source records, photography, or functionality exists.
